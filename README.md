## 审核与评论帧工具箱 1.0.8

截图范围可直接选择 **左侧｜全部｜右侧**，自动记住上次的选择；一键截图和图片编辑使用相同范围。

自动识别同一编辑器中紧邻原图的右侧原生图片，并一起保留底图、标注框、网格和参考线。正常识别后无需手动补选；没有识别到右侧时才显示“选择右侧”。保留普通裁切和全景预览截图。

更新脚本后刷新标注页面即可使用。本地原生双图、普通裁切和全景预览已验证；实际项目页面请更新后确认效果。

## 清空标注并恢复待标注 v1.0.3

[安装 / 更新最新版](https://raw.githubusercontent.com/chengzi-1225/Insta360-chengzi/main/label-studio-reset-annotations.user.js) · [使用说明](docs/reset-annotations.md)

勾选任务或输入 ID，预览通过后可以直接清空。下载备份可选：未下载时删除弹确认；已下载则直接执行，下载本身不弹确认。清理标注、草稿及预标注，保留任务与原始视频并核查状态。

支持跨页勾选与全选筛选结果，读取完整范围并核对数量，避免6000条只读取24行。预览与执行最多并行处理3个任务，复用删除后的核查结果减少请求。

平台 HTTP 422“已经审核并打分，不能直接删除”仍须平台支持的处理流程。当前版本**尚未实现自定义审核、评分、审核员和标注员关联清理**，可用“导出接口诊断”只读采集字段与接口说明；状态变化日志含前后值。

36项本地模拟测试通过，真实项目仍待验证。固定安装链接和自动更新地址保持不变。

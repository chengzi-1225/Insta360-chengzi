# 工作台 1.8.3：工作区选择与视觉调整

目标：日常查看个人产量和比较项目时，筛选清楚、文字可读；解决原生工作区菜单在几十个选项时铺满屏幕的问题。

采用与项目一致的白色搜索菜单。工作区支持名称和 ID 搜索、全部工作区、当前选择标记、键盘方向键和 Escape；选项区最高 280px，在菜单内滚动。目录读取只取工作区名称，不触发产量查询。读取失败可以重试，账号变化继续清除旧数据。

界面保留四项核心指标和项目表格，使用浅灰背景、白色筛选面板、12–13px 正文和一致的控件高度。修改筛选后显示简短提示；加载时显示紧凑占位行，不生成模拟数字。保留返修超时恢复和已有数据口径。

验证：70 个工作区、长名称、搜索不查询产量、精确选择、键盘、失败重试、加载状态、320–1920px 菜单边界；回归本人统计、CSV、分页、角色与账号切换、待处理超时恢复。

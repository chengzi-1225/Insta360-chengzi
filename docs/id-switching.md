## 本次优化

- 空格默认播放 / 暂停视频，优先点击平台原生播放控件，使标注时间轴同步。长按只触发一次，输入文字、弹窗和录制快捷键期间不触发播放。
- 快捷键设置新增「播放与更新」分组，将「更新数值」和「更新任务」分开。两个更新默认均未绑定，点击对应按键框后按下你需要的按键并保存。
- 数值更新识别相机参数面板里的更新，任务更新识别任务栏的更新；不会把提交或草稿当作更新。按钮隐藏、禁用或存在歧义时不执行，也不会跨类型点击。
- 不再按 lil-gui 的数字编号寻找更新按钮，编号变化或面板重排不会点到重置按钮。
- 自动发现的同名「更新」显示「数值调整」「任务操作」分组，便于辨认。其它页面按钮与标签仍支持自动扫描、搜索和改绑。
- 旧版「更新 / 保存」及旧版占用空格的绑定会释放。旧版自动扫描的更新类绑定也需重新设置；其它自定义按键保留。新设置刷新后保持。
- 清空标签、人物组操作原有的自动更新只作用于数值，不会连带提交任务。
- 保留 A / D 导航、S 循环比例、预设多选和鼠标框选、选中显隐、标签同步（默认关闭，可在“快捷键设置”里的“辅助功能”区域开启）、原生删框撤回。原生撤回和重做仍由平台负责。

## 视频测试

双击「视频与更新-测试页面.html」，页面内嵌真实视频和本次脚本，可离线使用。

1. 在输入框外按空格，观察播放进度，再按一次暂停；两个更新计数均应为 0。
2. 打开「快捷键设置」→「播放与更新」，自设数值和任务更新的按键（测试时可用 F8 / F9），保存。
3. 分别按键，确认只增加对应计数；改动 FOV 后更新数值可看到应用结果。
4. 在 FOV 输入框内按空格，或在设置中录制空格，不会误触发播放或更新。
5. 刷新后，绑定保持。可在自动扫描区域搜索「更新」，查看两个按钮的分组。

## 推荐测试顺序

1. 点预设按钮展开菜单，用鼠标拖动框住多个比例，再按 A / D 切换 ID。
2. 勾选「全选」，确认所有预设选中；从已勾选的比例开始拖动，批量取消，确认出现半选状态；也可试 Alt 拖动取消。
3. 点「新增示例框」和「移动当前框」，用右侧原生「撤回 / 重做」恢复。
4. 选中框后点「删除选中框」，再撤回；在右侧调整角度、构图，确认默认不自动同步；打开「快捷键设置」，在“辅助功能”中点击「标签同步：开」后，再切换相邻 ID 测试同步。
5. 切换「更多 ID」或「空任务」，检验长列表与空状态；「重置示例」恢复初始数据。
6. 打开「快捷键设置」录制按键；展开「页面按钮与标签」可搜索页面按钮。重复使用已有按键可查看冲突提示，取消可丢弃修改。

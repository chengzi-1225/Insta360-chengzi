# ID 切换 v3.19.1

[安装 / 更新脚本](https://raw.githubusercontent.com/chengzi-1225/Insta360-chengzi/main/insta360-IDswitching.user.js) · [常显与框选演示（下载后打开）](demos/insta360-always-visible.html) · [视频与更新演示（下载后打开）](demos/insta360-id-switch.html) · [TXT 备份](downloads/insta360-IDswitching-3.19.1.txt)

安装后刷新标注页面。在左侧 Regions 的“显示控制”工具栏点击 **常显设置**，勾选立即生效。默认保留人物-1、人物-2；需要时可取消。常显框与当前点击的框共同显示，其余框继续随点击或快捷键切换。

## 批量常显

- **比例**：多选 9:16、16:9、1:1、4:3、3:4，也能添加自定义比例，例如 2.35:1。相同比例会合并匹配，如 1920:1080 与 16:9。
- **文本标签**：输入“主体”“杂物”等文字，每次添加一项。默认“完整标签”只匹配同名标签；选择“包含文字”后，“杂物”也会匹配“杂物-背景”。按标签文字匹配，不按列表序号匹配；文字按字面处理。可单项取消、全选、批量取消或删除规则。每条最多 80 个字符，最多保存 100 条。
- **具体 ID**：勾选当前任务内的框，可搜索标签、ID 或比例并批量处理筛选结果。同名框分别设置。

人物开关、比例和文本设置在本浏览器当前站点保存，刷新后保留。取消勾选的文本也保留在列表中，方便以后重新启用。具体 ID 只用于本次页面的当前任务；刷新、换任务或换标注时清空，不会带到其他任务。同一标注保存、原生撤回重建后，仍按稳定 ID 保留。

## 拖动框选

在比例、文本或具体 ID 列表中按住鼠标左键拖动：

- 从未勾选项开始：批量勾选命中的项目；从已勾选项开始：批量取消。
- 按住 **Alt** 拖动：始终批量取消。空白处开始默认勾选。
- 拖动时显示命中预览，松手后一次生效。只处理当前列表可见的筛选结果。
- **Esc** 取消本次拖动，保留设置窗口；关闭窗口、失焦、切换任务或重建当前列表也会取消未完成的拖动。

普通单击、Tab 和空格勾选继续可用。设置窗口内输入文字不会触发业务快捷键。关闭“选中隐藏”可显示全部框；重新开启时应用常显设置。

## 播放、更新与快捷键

- A / D 切换 ID；S 循环比例。常显设置独立于导航范围。可在“快捷键设置”中改绑。
- 空格默认播放 / 暂停视频；优先使用平台原生播放控件。长按只触发一次，输入和弹窗期间不会误触发。
- “快捷键设置 → 播放与更新”分别设置“更新数值”和“更新任务”，两个更新默认均未绑定。同名按钮按所在面板区分，不会把提交或草稿当作更新。
- 标签同步默认关闭，在“快捷键设置 → 辅助功能”中单独开启。预设多选与框选、原生删框撤回均保留。

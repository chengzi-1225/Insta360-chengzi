# Label Studio 油猴脚本

## 安装

1. 浏览器安装 Tampermonkey（油猴）。
2. 打开下面任意一个 `.user.js` 文件，复制全部内容，在 Tampermonkey 新建脚本后粘贴并保存；也可以直接把文件拖到 Tampermonkey 管理页面。
3. 登录 `https://label.insta360.com` 后刷新页面。页面右下角会出现对应按钮。

## 通过率与全部评论（合并版 1.4.0）

脚本：`Insta360_框ID通过率统计.user.js`

更新原通过率脚本后，刷新平台页面，点击右下角“通过率 / 评论导出”。输入框留空并点击“读取当前页面项目”，脚本会自动读取当前页面显示的项目卡片；也可以手动输入一个或多个项目 ID。读取后勾选需要的项目，可分别统计通过率或读取评论。

### 历史通过率

设置开始日期和结束日期，点击“统计选中项目”。界面会读取项目包里的全部任务和任务历史记录。

每一条历史通过或历史驳回都单独计数，同一任务多次审核不会去重。通过率公式为：

`历史通过次数 ÷（历史通过次数 + 历史驳回次数）`

开始日期和结束日期都包含当天。`REVIEWED_ACCEPTED`、`REVIEW_ACCEPTED` 等状态计为通过；`REVIEWED_REJECTED`、`REVIEW_REJECTED` 等状态计为驳回；普通提交、返工、返修和创建记录不计入通过率。

可复制通过率汇总表，或导出 CSV 和完整 Excel。Excel 包含标注员通过率、项目汇总、历史记录和待核对与口径。如果也已读取评论，完整 Excel 会同时包含下述评论工作表。任务或历史接口读取失败会保留已读取结果，并在明细里列出原因，不会把失败记录当成通过。

读取速度已优化：任务列表按较大分页读取，任务详情和历史记录并行请求，同时保持失败明细和停止按钮可用。

### 全部评论按标注员合并

勾选项目后直接点击“读取全部评论”，无须先统计通过率。评论读取所选项目的**全部时间**，不受历史开始日期、结束日期限制。

- **同一项目、同一标注员**：优先按标注员账号 ID 合并，评论在单元格内换行排列，保留任务 ID、评论 ID、时间、评论人、已解决状态、图片信息和任务链接。不同账号的重名人员分别保留并显示 ID。
- **不同项目**：即使标注员相同，也分别建表，不会混在一起。
- 每个项目各有“标注员汇总”和“评论明细”两张 Excel 表；另附“任务汇总”“读取状态”。
- 标注员按评论关联的标注 ID 确定；未关联标注的任务评论使用任务最新有效标注员。无账号 ID 时按姓名匹配；有重名歧义或归属不明的按任务分开保留并标记待核对。
- 相同文字的不同评论分别保留。长内容分成续行，不截断；汇总计数只显示在第一段。

点击“导出评论 Excel”可单独导出评论，也可以“导出合并评论 CSV”。CSV 保留项目列；Excel 按项目分表。

停止评论读取时，本次未完成的评论不生成结果，已有通过率仍保留。修改历史日期只需重新统计通过率，全部时间的评论仍保留；修改项目输入或勾选项会清空旧结果，防止项目范围混淆。

脚本使用当前浏览器的登录会话，无须填写 Token。已解决评论和只有图片的评论也会保留；图片以链接或原始信息列出。任务或评论读取失败、姓名归属待核对时，页面会提示，文件名带“待核对”，读取状态表保留原因。失败任务的评论条数留空，与成功读取后“0 条评论”区分。

### 从旧评论脚本切换

合并版仍使用原通过率脚本的名称、文件名和更新地址，可直接覆盖更新。请在油猴管理页面停用旧的 `Insta360_全部评论导出.user.js`，以后从“通过率 / 评论导出”统一操作。

## 旧版独立评论导出（保留兼容）

脚本：`Insta360_全部评论导出.user.js`

点击“全部评论导出”，输入一个或多个项目 ID，例如 `10532,10533,10534`，点击“开始读取全部评论”。脚本会读取项目里的全部任务和评论，包括评论文字、评论人、评论时间、是否已解决、标注员、审核员和任务链接。已解决的评论、只有图片没有文字的评论也保留，评论图片以链接或原始信息列出。

读取完成后可以导出：

- 任务汇总 CSV
- 评论明细 CSV
- Excel（每个项目一张评论工作表，另附任务汇总、读取状态）

脚本使用当前浏览器的登录会话，不需要在脚本里填写 Token。项目很大时可以等待进度完成。任务或评论读取失败、分页数量不完整时，文件名带“待核对”，读取状态表会保留原因；失败任务的评论条数留空，与“0 条评论”区分。

## 文件位置

- `Insta360_框ID通过率统计.user.js`
- `Insta360_全部评论导出.user.js`

日常使用合并版即可，旧版独立评论脚本仅保留兼容。

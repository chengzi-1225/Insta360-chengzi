# Label Studio 油猴脚本

## 安装

1. 浏览器安装 Tampermonkey（油猴）。
2. 打开下面任意一个 `.user.js` 文件，复制全部内容，在 Tampermonkey 新建脚本后粘贴并保存；也可以直接把文件拖到 Tampermonkey 管理页面。
3. 登录 `https://label.insta360.com` 后刷新页面。页面右下角会出现对应按钮。

## 框 ID 通过率

脚本：`Insta360_框ID通过率统计.user.js`

点击“历史通过率”，输入一个或多个项目 ID，点击“读取项目列表”，勾选需要统计的项目，再设置开始日期和结束日期，最后点击“统计选中项目”。界面会读取项目包里的全部任务和任务历史记录。

每一条历史通过或历史驳回都单独计数，同一任务多次审核不会去重。通过率公式为：

`历史通过次数 ÷（历史通过次数 + 历史驳回次数）`

开始日期和结束日期都包含当天。`REVIEWED_ACCEPTED`、`REVIEW_ACCEPTED` 等状态计为通过；`REVIEWED_REJECTED`、`REVIEW_REJECTED` 等状态计为驳回；普通提交、返工、返修和创建记录不计入通过率。

可复制汇总表，或导出 CSV 和完整 Excel。Excel 包含标注员通过率、项目汇总、历史记录和待核对与口径。任务或历史接口读取失败会保留已读取结果，并在明细里列出原因，不会把失败记录当成通过。

## 全部评论导出

脚本：`Insta360_全部评论导出.user.js`

点击“全部评论导出”，输入一个或多个项目 ID，例如 `10532,10533,10534`，点击“开始读取全部评论”。脚本会读取项目里的全部任务和评论，包括评论文字、评论人、评论时间、是否已解决、标注员、审核员和任务链接。已解决的评论、只有图片没有文字的评论也保留，评论图片以链接或原始信息列出。

读取完成后可以导出：

- 任务汇总 CSV
- 评论明细 CSV
- Excel（每个项目一张评论工作表，另附任务汇总、读取状态）

脚本使用当前浏览器的登录会话，不需要在脚本里填写 Token。项目很大时可以等待进度完成。任务或评论读取失败、分页数量不完整时，文件名带“待核对”，读取状态表会保留原因；失败任务的评论条数留空，与“0 条评论”区分。

## 文件位置

- `Insta360_框ID通过率统计.user.js`
- `Insta360_全部评论导出.user.js`

这两个文件可以单独安装，互不影响。

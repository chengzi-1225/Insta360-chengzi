# Insta360 统计数据合并工具

项目 ID、项目进度与周报、历史通过率、全部评论共用一个“统计数据”入口和一份项目清单。使用当前网页登录状态，无须填写 Token。

## 安装与升级

推荐使用 `project-stats/copy-project-ids.user.js`，交付副本名为 `Insta360_项目统计数据.user.js`，版本 **2.0.0**。油猴中仍显示原名称“Insta360 项目 ID 一键复制”，方便直接覆盖旧版并保留累计项目、剔除记录和历史快照。

1. 打开油猴管理页面，找到原“Insta360 项目 ID 一键复制”，用新版完整内容替换并保存；首次使用则新建脚本。
2. 停用原独立“全部评论导出”和另一份“框ID通过率统计”，只启用这个合并版。
3. 刷新 Insta360 项目页面，点击顶部工具栏“隐藏项目”旁的**统计数据**。没有顶部工具栏时，入口显示在页面右侧。

原通过率用户也可直接升级 `Insta360_框ID通过率统计.user.js` 至 **1.5.0**，功能相同。两份安装包任选一个；需要继承原 ID 脚本的累计项目和快照时，使用上面的 2.0.0 原位升级。

## 共用项目清单

- 默认自动识别本页已加载且未隐藏的项目卡片；在项目详情页没有卡片时，使用当前项目。
- 左侧勾选或剔除项目，三个功能共用同一范围。左侧搜索只筛选显示，不改变搜索之外的勾选；提示会显示含搜索外项目的选中总数。“全选 / 全不选”只作用于搜索结果。
- 跨页选项目时，逐页点“累计本页”，最后切换“累计项目”核对。重复 ID 自动去重。
- 展开“粘贴项目 ID / 链接”，可粘贴项目 ID、同站项目链接，或 `idlist = [10115, 10286]`。加入后切换到累计清单，不会立即查询。
- “复制所选 ID”直接复制当前勾选；“复制格式 / 累计管理”中保留本页、累计复制及清空累计。清空累计不会删除历史快照。

修改项目范围会停止旧查询并清空旧结果，请重新读取。切换右侧功能页签会保留当前查询和结果。一次只读取一类数据，可用顶部“停止当前读取”取消；收起窗口后查询继续，离开项目相关页面会停止。

## 项目进度

点“项目进度”后“统计所选项目”，查看总任务、已标注、已审核、未标注、两类进度及审核通过和驳回数。可保存本期快照、查看同组历史快照和复制周报。

项目进度反映平台当前汇总，与下面按每次历史审核计算的通过率口径不同。报告日期只决定快照归属，不会改变平台数据。快照只比较同一工作区、同一组项目的更早记录；净变化可能为负数。数据不完整或查询未结束时不能保存快照。

## 历史通过率

切换“历史通过率”，设置开始和结束日期，再点“读取历史通过率”。首尾日期均包含当天。每一条历史通过或驳回单独计数，同一任务多次审核分别统计：

`通过率 = 历史通过次数 ÷（历史通过次数 + 历史驳回次数）`

普通提交、创建、返工和返修不计入审核次数。可复制汇总、导出 CSV 或 Excel，Excel 包含标注员通过率、项目汇总、历史记录和待核对与口径。

任务详情和历史并行读取，页面显示读取进度。接口失败、人员信息缺失会保留可追溯信息和提示，不会把失败记录算成通过。

## 全部评论

切换“全部评论”后点“读取全部评论”，无须先统计通过率。评论覆盖所选项目的**全部时间**，不受历史通过率日期限制。

- 同一项目、同一标注员优先按账号 ID 合并，评论竖向换行排列；不同账号的同名人员分别保留并显示 ID。
- 不同项目分别生成“标注员汇总”和“评论明细”工作表，即使标注员相同也不会混在一起。
- 保留任务 ID、评论 ID、时间、评论人、已解决状态、图片信息和任务链接；已解决、仅图片及相同文字的不同评论均保留。图片以链接或原始信息列出。
- 标注员按评论关联的标注确定；没有关联标注时使用任务最新有效标注员。姓名无法明确对应账号或归属不明时按任务分开，标为待核对。长内容分为续行，不截断。

可单独导出评论 Excel 或合并评论 CSV。读取失败和不完整分页列在“读取状态”，失败任务条数留空，成功无评论显示 0。需要核对的文件名带“待核对”。取消本次未完成的评论读取时，不生成本次结果。

## 一次导出与窗口操作

顶部“导出已读数据 Excel”会把当前项目范围下已读取的项目进度、历史通过率和全部评论装入一个文件。附“本次导出范围”表，分别标明哪些功能已读取及历史日期；没有读取的功能不会被写成 0。

三个页签的结果分别保留，修改历史日期只清空历史通过率，已有全部时间评论和项目进度保留。

再次点击“统计数据”、右上角关闭或按 Esc 可收起，重新打开保留本页结果。窗口可拖动右下角调整大小；“最大化”和“恢复默认大小”可快速调整，小屏自动上下排列。

## 旧独立评论脚本

`Insta360_全部评论导出.user.js` 保留兼容，但日常请停用，统一使用合并版。它的旧导出格式与新版按标注员合并的格式不同。

# Insta360 我的工作台 · 1.8.0 数据浏览优化版

## 先看测试页

下载并双击 [`insta360-workbench.html`](demos/insta360-workbench.html)，无需安装、登录或联网即可体验。页面默认展示标注数据，左侧可以切换审核；手机宽度下使用底部切换按钮。

测试页全部使用模拟数据，不会向真实平台查询或提交。左下角可切换日常、多项目、缺失字段、零值、空数据、接口失败、慢查询、账号切换等场景。测试页的返修/返工按钮仅显示真实平台将使用的目标路径。

## 安装脚本

在 Tampermonkey 中导入 `Insta360我的工作台.user.js`，保存并启用。已有同名“我的工作台”脚本时替换旧版，避免两份同时启用。刷新 Insta360 标注平台，在标注中心或审核中心侧栏打开“我的标注”或“我的审核”。

## 查看和比较数据

1. 选择日期、工作区，点击“查询 / 刷新”。通过“项目范围与显示字段”可按项目名称或多个项目 ID 查询服务器，并选择显示列。
2. 在“搜索当前结果”输入项目名称或 ID，即时筛选已有数据；总览、明细合计、待处理清单会同步变化，不重新请求接口。服务器查询条件则在点击查询后才应用，修改时显示提示。
3. 点击任一表头切换升序/降序。默认按新标注提交或已审核数量降序；缺失字段始终排在最后。项目名下蓝条表示其产量相对当前匹配项目中最高产量的比例。
4. 明细支持每页 10 / 20 / 50 项。表头、项目名称列和合计行固定，宽表可横向滚动；合计覆盖全部匹配项目，不限于当前页。
5. “导出 CSV”导出全部匹配项目及当前勾选列，包含查询账号、日期、范围与统计说明。缺失字段留空，真实零值保留 0；查询未完成或失败时不可导出。
6. 返修/返工清单可按类型筛选，点击按钮进入平台原生处理流程。待处理计数包含历史遗留数据，不受产量统计日期影响。

## 数据口径

- 仅统计当前登录账号，继续保留账号复核、非本人记录排除、完整分页与异常提示。
- 缺失字段显示“—”，不会作为 0 合计；总览显示有值项目覆盖数。
- 准确率先合计通过和驳回再计算，只纳入两项均有值的项目；分母为 0 显示“—”。
- 本人 regions 使用本人所选日期统计。项目 regions 总数是全部成员、全部日期的累计参考，默认关闭。
- 新标注提交与返修/返工更新分别展示。

## 验证范围

已通过数据逻辑检查、15 组浏览器交互检查、320–1440px 宽度检查，以及交付脚本原文在标注/审核路由下的模拟接口核对。所有验证使用本地模拟数据；真实平台接口仍需在登录后的页面使用确认。

主脚本由 1.7.0 版本优化而来。正式脚本位于仓库根目录，自动更新地址沿用原有文件名。

## 仓库内复现

需要 Node.js。浏览器检查还需 Python Playwright 和本机 Chrome；安装依赖后运行：

```sh
cd workbench
npm run build
npm test
python3 tests/browser-check.py
python3 tests/production-check.py
```

本地预览可运行 `npm run demo`，然后打开 `http://127.0.0.1:8778`。构建产物保存到 `docs/demos/insta360-workbench.html`，检查结果和截图保存在 `workbench/preview/`。

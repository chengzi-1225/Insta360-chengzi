# Insta360 我的工作台 · 1.8.3 数据浏览优化版

## 先看测试页

双击 `工作台优化版-测试页面.html`，无需安装、登录或联网即可体验。页面默认展示标注数据，左侧可以切换审核；手机宽度下使用底部切换按钮。

测试页全部使用模拟数据，不会向真实平台查询或提交。左下角可切换日常、多项目、缺失字段、零值、空数据、接口失败、慢查询、返修超时重试、账号切换等场景。测试页的返修/返工按钮仅显示真实平台将使用的目标路径。

## 安装脚本

在 Tampermonkey 中导入 `insta360-workbench.user.js`，保存并启用。已有同名“我的工作台”脚本时替换旧版，避免两份同时启用。刷新 Insta360 标注平台，在标注中心或审核中心侧栏打开“我的标注”或“我的审核”。

## 查看和比较数据

1. 按顶部一行选择“工作区 → 项目名称 → 项目 ID（可多输）”，点击“查询 / 刷新”。项目下拉支持搜索、全部项目和精确选择；也可按名称关键词查询。日期在上一行，“列设置”单独控制显示列。
2. 在“搜索当前结果”输入项目名称或 ID，即时筛选已有数据；总览、明细合计、待处理清单会同步变化，不重新请求接口。服务器查询条件则在点击查询后才应用，修改时显示提示。
3. 点击任一表头切换升序/降序。默认按新标注提交或已审核数量降序；缺失字段始终排在最后。表头采用短名称，悬停可查看完整统计口径。
4. 明细支持每页 10 / 20 / 50 项。表头、项目名称列和合计行固定，宽表可横向滚动；合计覆盖全部匹配项目，不限于当前页。
5. “导出 CSV”导出全部匹配项目及当前勾选列，包含查询账号、日期、范围与统计说明。缺失字段留空，真实零值保留 0；本人统计未完成或失败时不可导出；独立的待处理查询失败不会阻止导出已完成的本人产量。
6. 页面底部的返修/返工默认折叠。展开后可按类型筛选，点击按钮进入平台原生处理流程。待处理计数包含历史遗留数据，不受产量统计日期影响。

## 1.8.3 工作区与视觉优化

- 工作区与项目统一为白色搜索菜单，支持名称 / ID 搜索、当前选择标记和键盘操作。工作区选项区最高 280px，在内部滚动，避免系统菜单铺满屏幕。
- 增大筛选、项目名称与数字字号，提高文字对比度，统一控件高度和表格间距；保留四项核心指标和紧凑表格。
- 筛选未应用提示改为简短行内说明，加载时显示占位行，等待数据返回后逐步展示。
- 工作区读取失败可单独重试，搜索和选择不会触发产量查询；账号核对与超时恢复继续保留。
- 测试页包含 70 个工作区，便于直接检查长列表、搜索及窄屏菜单。

## 1.8.2 筛选与超时处理

- 参照平台筛选样式，工作区、可搜索项目下拉、多个项目 ID、查询和重置直接展示；列设置单独收起。
- 项目选项只读取名称、ID 和工作区，切换工作区会重新限定选项；同名项目按 ID 精确区分。
- 下拉中的搜索不会查询产量，选好后点击查询才应用。按项目选择与手填 ID 冲突时明确提示。
- 返修 / 返工个人计数由每批 100 个项目降为 10 个，最多两个请求同时执行；超时、网络异常及 HTTP 502/503/504 自动重试一次。权限、登录失败与主动取消不重试。
- 一部分返修项目失败时保留本次已取得的数据，并标明合计未完整；可点击“仅重试待处理”，无需重查产量。状态不会将待处理失败显示为全部完成。
- “重置”恢复当前页面工作区、全部项目、清空手填 ID；点击查询后应用。窄屏自动排列为两列。

## 1.8.1 界面精简

- 日期筛选保持紧凑，账号与状态合并为单行页头。
- 核心指标固定为 4 项，使用紧凑数字栏；字段设置只影响项目表列和导出列。
- 标注显示新提交、返修/返工更新、准确率和本人 regions；审核显示已审核、通过、驳回和本人 regions。
- 去掉大卡片、重复标题、页内跳转导航、装饰条和数字动画，直接显示精确数值。
- 返修/返工和统计说明默认折叠。

## 数据口径

- 仅统计当前登录账号，继续保留账号复核、非本人记录排除、完整分页与异常提示。
- 缺失字段显示“—”，不会作为 0 合计；总览显示有值项目覆盖数。
- 准确率先合计通过和驳回再计算，只纳入两项均有值的项目；分母为 0 显示“—”。
- 本人 regions 使用本人所选日期统计。项目 regions 总数是全部成员、全部日期的累计参考，默认关闭。
- 新标注提交与返修/返工更新分别展示。

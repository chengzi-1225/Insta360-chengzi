# Regions 直接清空并提交 v3.2.1

[安装 / 更新](https://raw.githubusercontent.com/chengzi-1225/Insta360-chengzi/main/label-studio-regions-clear-submit.user.js)

基于用户提供的 v3.2.0 修改，已删除“预览任务”“核对快照”和预览表格二次勾选。保留同一名称和 namespace，安装时可覆盖原来的 Regions 脚本；自动更新地址固定。

## 使用

1. 停止正在运行的旧脚本并等当前任务结束，再安装更新、刷新项目数据页。
2. 打开“Regions 清空并提交 v3”，输入任务 ID，或点击“导入页面勾选 / 全选”。也可以填入当前打开任务。
3. 点击“直接清空并提交”，确认项目和任务数量后立即逐条处理，无需先预览。
4. 查看每条任务的执行进度；结束后可下载执行记录，再刷新列表核对结果。

ID 支持逗号、换行、分号分隔，以及井号前缀；重复 ID 自动合并，每批最多 10000 个。执行范围为确认时输入框中的 ID。确认后输入框的修改只用于下一次执行。

## 清理和提交方式

每条任务按原脚本的原生编辑器流程：打开任务 → 等待历史和媒体加载完成 → 读取默认选中的标注 → 删除全部 reframe 轨迹及相连关系 → 点击原生提交 → 等待重新加载 → 从服务器回读提交内容。脚本逐条完成后进入下一条，不会先把所有任务打开一遍。

成功条件是已收到原生提交成功事件、服务器中该标注结果与清理后的预期一致、reframe 轨迹为 0、任务状态为 `ANNOTATED`（已提交）。当前标注没有轨迹时跳过，避免重复提交。遇到只读、内容变化、原生校验拦截、提交超时或回读不一致时停止，不自动重试提交。

本版沿用提供脚本的处理范围：清理默认标注中的 Regions，保留视频级分类、其他标注版本和机器预测原始记录。它完成后是“已提交”，不是把任务恢复待标注的旧版 API 工具。脚本不要求下载备份。

## 停止与记录

“当前任务完成后停止”会让当前执行中的任务完成清空、提交和回查，然后停止后续任务；已经提交的清空不会自动恢复。若当前步骤失败，立即停止后续步骤和任务。

界面表格最多显示当前位置附近 300 个任务，以控制大批量时的页面开销；下载执行记录包含全部已开始任务及失败阶段、提交标注 ID。尚未开始的任务数量会单独显示。

## 验证

14 项本地模拟测试通过，覆盖三个任务直接清空的顺序、跳过空轨迹、当前任务完成后停止、各阶段失败停止、不一致时不提交、分类保留、ID 校验、无预览即可执行、取消确认不读取、确认期间范围变化拦截。原生编辑器适配部分沿用用户提供的脚本；尚未在真实项目执行本修改版。

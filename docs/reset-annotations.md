# 清空标注并恢复待标注 v1.0.3

[安装 / 更新最新版](https://raw.githubusercontent.com/chengzi-1225/Insta360-chengzi/main/label-studio-reset-annotations.user.js)

安装后油猴会按固定地址检查更新，也可以点击工具底部“安装 / 更新”。覆盖安装后刷新项目列表，面板底部应显示 v1.0.3，请勿同时启用多个副本。

## 使用

1. 勾选任务，点击“读取已勾选任务”，或直接输入任务 ID。
2. 点击“预览范围”，核对任务数量和内容数量。
3. 点击“清空并恢复待标注”。下载备份是可选的；没有下载本次备份时会弹确认提醒，取消则不删除；已点击下载本次备份时直接执行，不重复弹窗。下载备份本身不弹确认。

脚本在每个任务开始写入前仍会自动保存浏览器本机备份；备份失败则停止。可以“导出本机备份”。备份不等于平台原生撤销，当前没有自动恢复功能。

## 清理范围与当前限制

当前实现删除所选任务的标注、跳过记录、草稿和预标注，保留任务 ID 和原始数据，再核查待标注状态。任务及视频不会被删除或重新导入。

用户要求的最终目标是保留视频、清除其他业务关联信息，包括审核结果、评分、审核员和标注员关联。**当前版本尚未实现平台自定义的审核、评分和人员关联清理**，也不会宣称这些信息已经清空。平台必填字段和任务 ID 需要保留。

- HTTP 422“已经审核并打分，不能直接删除”来自平台的删除限制。没有确认删除的记录时显示失败；若已经移除过草稿等记录，会显示部分完成并保留清单。不尝试猜测撤销接口。
- `annotations[id=...].state` 变化会停止删除；新版日志附变化前后值，结果文件含 `changeValues`。状态变化不能一概忽略。
- 遇到审核、评分或人员关联清理问题，在 ID 框保留目标 ID，点击“导出接口诊断”。仅对第一个任务读取字段结构及 OPTIONS 接口说明，不发起删除或修改。诊断文件用于进一步确认平台支持的清理入口；不要把真实诊断文件或备份上传到公开仓库。

## v1.0.3

- 改用平台 `dataManager.store.currentView.selected` 读取跨页勾选，支持显式的完整 ID 列表和“全选当前筛选结果”。
- 全选时保留当前筛选与排除项，逐页读取并核对总数，检测重复分页、筛选被忽略、项目或勾选变化。无法读齐会停止，不会悄悄退回可见的 24 行。
- 下载备份变为可选；未下载时删除弹确认，已下载不重复弹窗。
- 修正 422 状态报告，新增变化前后值和只读接口诊断。
- 更新本地测试页面：正常、6000 条全选仅显示 24 行、审核评分 422、预览后状态变化、内容已空状态未更新、删除响应超时。
- 测试页“仅演示：保留视频，其余业务数据清空”按钮用于展示完整目标效果，只修改模拟数据，**不是线上审核/评分清理接口已实现的证明**。

## v1.0.2

- 移除人工确认勾选框，增加 GitHub 稳定安装和更新链接。
- 预览和执行最多同时处理 3 个不同任务，同一任务内顺序删除并回查。
- 复用删除后的完整核查结果；四条记录的模拟任务，执行阶段完整读取从 10 次减至 6 次。耗时取决于网络和服务器。

## 验证

36 项本地模拟测试通过，覆盖跨页 6000 条范围、分页异常、备份可选的四种交互、422 失败/部分完成、状态变化、完整目标效果模拟、内容变化拦截、备份失败、超时及最终状态核查。尚未在真实项目验证 v1.0.3；真实平台的审核、评分和人员关联清理仍待确认接口。

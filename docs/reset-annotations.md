# 清空标注并恢复待标注 v1.0.2

[安装 / 更新最新版](https://raw.githubusercontent.com/chengzi-1225/Insta360-chengzi/main/label-studio-reset-annotations.user.js)

安装后油猴会按固定更新地址检查后续版本。也可以在工具面板底部点击“安装 / 更新”。已有旧版时覆盖安装即可；请不要同时启用多个副本。刷新项目列表，面板底部应显示 v1.0.2。

操作：勾选任务并点击“读取已勾选任务”，或输入任务 ID；预览范围、下载备份，然后点击“清空并恢复待标注”，在确认弹窗中选择“确定”。无需勾选确认框。选择“取消”不会执行删除。

会删除指定任务的标注（包括跳过记录）、草稿及预标注，保留任务 ID 和原始数据。执行前会额外保存一份本机备份，支持从面板导出。备份不等于平台原生撤销；本脚本未提供自动恢复功能。

## v1.0.2

- 移除“备份文件已保存”勾选框，改为显示项目、任务数量和清理数量的确认弹窗。
- 增加 GitHub 固定安装地址、自动更新信息和面板更新链接。
- 预览和执行最多同时处理 3 个不同任务；同一任务内仍按草稿、标注、预标注的顺序清理。
- 复用每次删除后的完整核查结果，减少整份视频标注的重复下载。例如四条记录的测试任务，执行阶段完整读取从 10 次减至 6 次。实际耗时取决于网络和服务器。
- 保留本地备份、内容变化检查、最终空内容和状态核查，以及停止操作。遇到异常时停止派发后续任务，已经发出的请求会回查完成后退出。

## v1.0.1 修正

- 避免更新时间、计时、头像及展示名称变化造成“预览后内容变化”的误判，兼容用户与项目引用返回 ID 或对象两种形式。
- 请求原始资源地址，减少临时资源地址变化造成的误判。
- 仍严格核对实际 result、对象 ID、跳过标记、草稿、预标注及任务状态；真正变化时停止，不强行删除。
- 拦截时列出具体变化字段，例如 `annotations[id=19672371].result[0].value` 或 `data.video`，结果日志中保存 `changeDetails`。
- 有失败时提示查看错误详情，避免误导为已经完成清空。

已通过本地模拟测试，覆盖取消确认不写入、确认后执行、并行上限、减少重复请求、内容变化拦截、备份失败、网络超时及待标注状态核查。尚未在用户真实项目上验证本版本。若仍失败，请导出结果日志或提供面板完整错误文字。
